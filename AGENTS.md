# UI / Design Rules

Para cualquier cambio visual en FindYourPet:

- Usar Jetpack Compose + Material 3 estable.
- No rediseñar la identidad visual existente.
- El diseño actual es la fuente de verdad.
- Respetar colores, tipografía, formas y jerarquías existentes.
- No introducir colores, tamaños, paddings o radios hardcodeados.
- Usar tokens del Design System.
- Soportar Light Theme y Dark Theme.
- No usar APIs alpha, beta o experimentales.
- No modificar lógica de negocio por cambios visuales.

La especificación completa está en:

`docs/design-system.md`

Antes de realizar cambios visuales, leer ese archivo.
